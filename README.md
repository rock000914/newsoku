# マイ・ニュースアンテナ

ニュー速あんてな風の自分用ニュースポータル。フレームワーク不要の静的サイトです。

## 使い方
1. `config.js` の `RSS_FEEDS` を編集
2. `index.html` をブラウザで開く（GitHub Pagesにそのままデプロイ可）

## 高速化の仕組み
- 6サイトを並列取得し、**取得できたものから順に表示**（全部待たない）
- キャッシュがあれば**即表示**し、期限切れのフィードだけ裏で更新（フィード単位で保存、最大24時間）
- rss2json が遅い/失敗した場合は allOrigins を並行して試し、先に成功した方を採用
- 1フィードあたり最大10秒で打ち切り（遅い/死んだサイトが全体を止めない）

## UI
- 記事ごとに**サイト名バッジ**を左端に表示（サイトごとに色分け、絞り込みチップと同色）
- 絞り込みチップに件数と取得状態（取得中/失敗）を表示
- テーマはOS設定に追従、🌙/☀️ で手動切替
- 読み進めている最中の自動更新は、画面を動かさず「新着あり」バーで通知

## 設定（config.js）
| 名前 | 内容 | 既定 |
|---|---|---|
| `CACHE_DURATION` | この時間内は再取得しない | 5分 |
| `CACHE_MAX_AGE` | 古くても先に表示する上限 | 24時間 |
| `FETCH_TIMEOUT` | 1フィードの最大待ち | 10秒 |
| `HEDGE_DELAY` | 予備経路を並行開始するまでの待ち | 2.5秒 |
| `MAX_ITEMS_PER_FEED` | 1フィードの取得件数 | 30 |
| `hue`（各フィード） | バッジ色 0-360（省略で自動） | 自動 |
